# Zombie Chips — сервер и бот

Сервер берёт каталог сборки из публичного GitHub, скачивает только файлы из каталога, проверяет размер и SHA-1, и хранит их в `data/modpack`. Пока обновление не завершилось, раздаётся предыдущая версия. `GET` и `HEAD` доступны по `/head`, `/journal`, `/objects/<sha1>`; диапазоны поддерживаются через aiohttp FileResponse.

Переменные окружения: `BOT_TOKEN` (секрет, не публиковать), `OWNER_TELEGRAM_ID` (числовой Telegram ID владельца), `PORT` (обычно задаёт Bothost), `PACK_DATA_DIR` (при необходимости), `PACK_MIRROR` (необязательно). В личном чате владельца команды `/status`, `/sync`. При старте синхронизация запускается автоматически.

Важно: папка `data` должна сохраняться при перезапусках и обновлениях контейнера. Для первой установки потребуется около размера сборки плюс место на обновления. Файлы старых версий специально автоматически не удаляются.
